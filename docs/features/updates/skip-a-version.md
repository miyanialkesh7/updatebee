Skip one offered plugin or theme version and leave automatic updates on for the next one. The item stays unblocked. A later version can install on the normal schedule.

You can skip a version from **Settings → Upcoming** or from the update panel on **Plugins** and **Themes**.

## From Upcoming

Open **Settings** and choose the **Upcoming** subtab. On a row that is still scheduled, the action is **Skip this version**. The Schedule column then shows **Skipped**.

**Schedule update** appears when that version is already skipped. Choosing it puts the version back on the schedule.

The rest of that table, including **Update now** and **Block updates**, is in the article Upcoming Updates.

## From the plugin or theme update panel

When a plugin or theme has an offer, its update panel shows the available version and **Skip this version**. If that version is already skipped, the panel says this version will be skipped, and the action changes to **Schedule update**.

Skipping here holds that version number only. **Block updates** on the same item hides every offer for it. The difference is in the article Blocked Updates.

A skipped automatic attempt is recorded in **Logs** with the status **Skipped**.

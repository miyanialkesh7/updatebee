**Block Untested Updates** skips automatic plugin and theme updates when the package has not been tested with this site's WordPress version.

Open **Advanced** and find the card **Block Untested Updates**. The description says automatic plugin and theme updates are skipped when the package has not been tested with this site's WordPress version.

## Turn the block on

The toggle is **Block untested updates**. The help text says individual plugins and themes can still allow untested updates from their own settings. Select **Save**.

The option starts off, so untested updates are allowed until you save the toggle on.

## Allow one item through

On **Plugins** or **Themes**, the gear opens **Plugin settings** or **Theme settings**. The toggle is **Untested Updates: Use site default for untested updates**. The help text says to turn this off to allow untested updates for this item.

When the site-wide block is off, the drawer shows: "Untested updates are already allowed for every plugin and theme."

**Save** in the drawer stores the choice for that item. Leaving the toggle on keeps the site default.

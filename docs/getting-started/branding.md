Agencies can change the name, description, author, and URL that WordPress shows for UpdateBee. The plugin files and the `updatebee` slug stay the same. Branding changes what people see on the Plugins screen, in the UpdateBee header, and in email and Slack alerts.

## Open the branding fields

1. Open UpdateBee. On a single site that is **Tools → Automatic Updates**. On Multisite, use the network admin path in the article UpdateBee on Multisite.
2. Open **Advanced**.
3. On the **Plugin branding** card, select the gear icon.

The card explains that these fields change how the plugin appears on the Plugins screen, in the admin header, and in emails and Slack alerts. Leave a field empty to keep the default.

## What each field changes

| Field | When it is filled in |
| --- | --- |
| **Plugin name** | Replaces the name on the Plugins screen, the UpdateBee header, and the name used in emails and Slack. The card shows **Shown as:** after you save a name. |
| **Description** | Replaces the Plugins-screen description. |
| **Plugin author** | Replaces the author on the Plugins screen. |
| **Plugin URL** | Replaces the plugin and author URLs on the Plugins screen. |

Select **Save**. **Cancel** discards unsaved edits. An empty field falls back to the header default. The name default is UpdateBee.

> [!NOTE]
> Branding is a display change. It does not rename the plugin directory, the text domain, or the settings stored for the network.

The optional toolbar menu is a different Advanced card. See the article Admin Bar Menu.
